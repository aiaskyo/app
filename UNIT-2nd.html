Labelling Cross-referencing / Labels

📖 Kya Hai? (What is it?)

Labelling matlab apne document ke kisi bhi part — jaise section, figure, table, ya equation — ko ek naam (label) dena aur phir us naam ke through usse refer karna. Jaise school mein chapters ko number milte hain, waise hi yahan hum LaTeX ko bolte hain: "yeh section ka naam 'intro' hai, aur yahaan pe uska number print karo."

🎯 Kyun Use Karte Hain?

Socho tumhare 50-page document mein ek section hai "Theory" — jo page 7 pe hai. Agar tum likho "See Section 3" aur baad mein ek naya section aane se sab numbers badal jayein, tum phir se hath se sab theek karoge. LaTeX mein \label aur \ref use karo — LaTeX automatically sahi number print karega. 🎉

🔧 Syntax
% Step 1: Label lagao
\label{tumhara-naam}

% Step 2: Refer karo
\ref{tumhara-naam}    % number deta hai
\pageref{tumhara-naam} % page number deta hai
💻 Working Example
\documentclass{article}
\begin{document}

\section{Introduction} \label{sec:intro}
% \label hamesha us cheez ke BAAD likhte hain jise label karna hai

Yeh introduction hai.

\section{Theory} \label{sec:theory}

Jaise humne Section~\ref{sec:intro} mein bataya (page~\pageref{sec:intro} par),
yeh theory section hai.

\begin{equation}
  E = mc^2 \label{eq:einstein}
\end{equation}

Equation~\ref{eq:einstein} Einstein ka famous formula hai.

\end{document}
📄 Output (PDF mein dikhai dega)
1 Introduction
Yeh introduction hai.

2 Theory
Jaise humne Section 1 mein bataya (page 1 par), yeh theory section hai.

E = mc²                                                                 (1)

Equation 1 Einstein ka famous formula hai.
💡 Tips

• Label names mein prefix use karo: sec: for sections, eq: for equations, fig: for figures, tab: for tables. Isse dhundna aasaan hoga.
• ~ (tilde) ek "non-breaking space" hai — yeh number ko agle line pe jane nahi deta. Hamesha Section~\ref{} likho, Section \ref{} nahi.

⚠️ Common Mistake

Overleaf mein do baar compile karo! Pehli baar LaTeX labels read karta hai, doosri baar sahi numbers fill karta hai. Agar "??" dikh raha hai, ek baar aur compile karo.

Table of Contents Vishay-Suchi / Index

📖 Kya Hai?

Table of Contents (TOC) matlab document ki vishay-suchi — jaise books ke shuru mein hoti hai jahan likha hota hai "Chapter 1 — Page 5, Chapter 2 — Page 12." LaTeX yeh automatically banata hai!

🎯 Kyun Use Karte Hain?

Bade documents, theses, reports mein reader ko pata chale ki kya kahan hai. Manually banane pe agar pages badlein to sab galat ho jayega. LaTeX khud sahi page numbers deta hai.

🔧 Syntax
\tableofcontents   % Yehi kaafi hai! Bas yeh ek command
💻 Working Example
\documentclass{article}
\begin{document}

\tableofcontents   % Yahan TOC print hoga
\newpage           % Naya page shuru karo

\section{Pehla Adhyay}
Yeh pehla section hai.

\subsection{Ek Sub-topic}
Yeh sub-section hai.

\subsubsection{Aur Chhota Topic}
Yeh sub-sub-section hai.

\section{Doosra Adhyay}
Yeh doosra section hai.

\section*{Unnumbered Section}
% Star (*) lagao to number nahi aayega
% Par yeh TOC mein bhi nahi aayega by default
\addcontentsline{toc}{section}{Unnumbered Section}
% Upar wali command TOC mein manually add karta hai

\end{document}
📄 Output (TOC page)
Contents

1    Pehla Adhyay                                                               2
   1.1   Ek Sub-topic                                                       2
       1.1.1   Aur Chhota Topic                                            2
2    Doosra Adhyay                                                         3
💡 Tips

• Depth control ke liye preamble mein likhो: \setcounter{tocdepth}{2} — iska matlab sirf section aur subsection tak dikhao (3 = subsubsection bhi).
• book class mein \chapter{} bhi hota hai jo TOC mein aata hai.

⚠️ Common Mistake

Hamesha do baar compile karo Overleaf mein, tabhi TOC sahi page numbers dikhayega!

Coloured Text Rangin Alfaz

📖 Kya Hai?

LaTeX mein text ka colour badal sakte ho — red, blue, green, ya koi bhi custom colour. Background colour bhi change ho sakta hai. Iske liye xcolor package use karte hain.

🎯 Kyun Use Karte Hain?

Important words highlight karne ke liye, presentation banane ke liye, ya sirf document ko sundar dikhane ke liye!

🔧 Syntax
\usepackage{xcolor}  % Preamble mein

\textcolor{colour-name}{tumhara text}  % Text colour
\colorbox{colour-name}{tumhara text}   % Background colour
{\color{colour-name} text here}         % Curly braces tak colour
💻 Working Example
\documentclass{article}
\usepackage{xcolor}   % Colour package load karo

\begin{document}

% Built-in colours
\textcolor{red}{Yeh laal hai!}

\textcolor{blue}{Yeh neela hai!}

\textcolor{green}{Yeh hara hai!}

% Custom colour (RGB se)
\textcolor[RGB]{128, 0, 128}{Yeh purple hai!}

% Hex colour
\textcolor[HTML]{FF8C00}{Yeh dark orange hai!}

% Background colour
\colorbox{yellow}{Highlighted text!}

% Apna colour define karo
\definecolor{myBlue}{HTML}{1a73e8}
\textcolor{myBlue}{Google wala neela!}

\end{document}
📄 Output
Yeh laal hai!
Yeh neela hai!
Yeh hara hai!
Yeh purple hai!
Yeh dark orange hai!
Highlighted text!
Google wala neela!
💡 Tips

Built-in colours: red, blue, green, cyan, magenta, yellow, black, white, gray, orange, violet, purple, brown, pink, teal, lime, olive. xcolor ke saath yeh sab milte hain!

⚠️ Common Mistake

\color{} command ke baad ka poora text us colour mein aa jaata hai jab tak curly braces band na ho. Hamesha {\color{red} text} likhо — curly braces mein band karo.

Boxes Dabbe / Frames

📖 Kya Hai?

LaTeX mein text ke chaaro taraf border/box laga sakte ho. Jaise notebooks mein important cheezein box mein likhte hain, waise hi!

💻 Working Example
\documentclass{article}
\usepackage{xcolor}
\usepackage{mdframed}   % Fancy boxes ke liye
\usepackage{fbox}       % Basic boxes

\begin{document}

% 1. Sabse simple box
\fbox{Yeh simple box hai!}

% 2. Puri line ka box
\fbox{\parbox{0.9\textwidth}{
  Yeh ek puri paragraph ki width ka box hai.
  Ismein lambi text aa sakti hai.
}}

% 3. Coloured box (xcolor ke saath)
\colorbox{cyan}{Yeh background coloured hai!}

% 4. mdframed se sundar box
\begin{mdframed}[
  backgroundcolor=yellow!20,  % 20% yellow
  linecolor=red,
  linewidth=2pt
]
Yeh ek sundar box hai!
Ismein paragraphs bhi aa sakte hain.
\end{mdframed}

% 5. makebox - fixed width box
\makebox[5cm][c]{Centered in 5cm}

\end{document}
📄 Output
Yeh simple box hai!

Yeh ek puri paragraph ki width ka box hai. Ismein lambi text aa sakti hai.
Yeh background coloured hai!

Yeh ek sundar box hai!
Ismein paragraphs bhi aa sakte hain.
💡 Tips

• tcolorbox package aur bhi powerful aur sundar boxes deta hai — thesis aur reports ke liye best hai.
• yellow!20 ka matlab hai 20% yellow colour (xcolor feature).

Theorems Siddhant / Pramanik

📖 Kya Hai?

Math ya science documents mein Theorem, Lemma, Corollary, Definition, Proof jaise special sections hote hain. LaTeX inhe automatically number karta hai aur special style mein dikhata hai.

💻 Working Example
\documentclass{article}
\usepackage{amsthm}   % Theorem package — ZARURI hai!
\usepackage{amsmath}  % Math ke liye

% Preamble mein define karo:
\newtheorem{theorem}{Theorem}
\newtheorem{lemma}{Lemma}
\newtheorem{corollary}{Corollary}
\newtheorem{definition}{Definition}
\theoremstyle{remark}  % Italic nahi, normal style
\newtheorem*{remark}{Remark}  % * matlab no numbering

\begin{document}

\begin{definition}
  Ek \textbf{prime number} woh natural number hai jo sirf 
  1 aur khud se divisible ho.
\end{definition}

\begin{theorem}[Pythagoras]
  Right-angled triangle mein: $a^2 + b^2 = c^2$
\end{theorem}

\begin{proof}
  % proof environment automatically "Proof." likhta hai
  Yahan proof likhenge... $\square$ automatically aata hai.
\end{proof}

\begin{remark}
  Yeh theorem 2500 saal purana hai!
\end{remark}

\end{document}
📄 Output

Definition 1. Ek prime number woh natural number hai jo sirf 1 aur khud se divisible ho.

Theorem 1 (Pythagoras). Right-angled triangle mein: a² + b² = c²

Proof. Yahan proof likhenge... □

Remark. Yeh theorem 2500 saal purana hai!

💡 Tips

• \newtheorem{theorem}{Theorem}[section] likho toh numbering section-wise hogi (1.1, 1.2, 2.1...).
• Square-box (□) proof ka end symbol hota hai — proof environment khud laata hai.

Comments Tippani / Private Notes

📖 Kya Hai?

Comments wo text hai jo PDF mein nahi dikhta — sirf .tex file mein rahta hai tumhare liye notes ke taur pe. Programming mein bhi comments hote hain na — same concept!

🔧 Syntax
% Yeh ek comment hai — PDF mein nahi aayega

% Percentage sign (%) se comment start hota hai
% Yeh line ka baaki hissa ignore ho jaata hai
💻 Working Example
\documentclass{article}
\usepackage{comment}  % Multi-line comments ke liye

\begin{document}

Yeh text PDF mein aayega. % Yeh comment PDF mein nahi aayega

% TODO: Yahan baad mein equation likhni hai
% NOTE: Is section ko check karna hai

Doosra paragraph.

% Pura block comment karna hai? comment package use karo:
\begin{comment}
  Yeh poora block PDF mein nahi aayega.
  Kai lines ho sakti hain.
  Matlab yeh sab chhupa hua hai!
\end{comment}

Teesra paragraph — normal hai.

\end{document}
📄 Output
Yeh text PDF mein aayega.

Doosra paragraph.

Teesra paragraph — normal hai.
💡 Tips

• Overleaf mein shortcut: Ctrl+/ (Windows) ya Cmd+/ (Mac) — selected text comment ban jaata hai!
• TODO comments likho apne liye: % TODO: equation add karni hai

⚠️ Common Mistake

Agar tumhare text mein actual % sign likhna hai (jaise "50% discount"), toh \% likho — warna LaTeX usse comment samjhega!

Spacing Jagah / Doori

📖 Kya Hai?

LaTeX khud spacing manage karta hai — lekin kabhi kabhi hume extra space, horizontal ya vertical jagah chahiye hoti hai. Inke liye special commands hain.

💻 Working Example
\documentclass{article}
\begin{document}

%--- HORIZONTAL SPACING (Seedhi jagah) ---
A\,B       % thin space (choti jagah)
A\;B       % medium space
A\quadB   % 1em space (ek M jaisi jagah)
A\qquadB  % 2em space (do M jaisi jagah)
A\hspace{2cm}B  % bilkul 2cm jagah
A\hfillB   % bachi hui puri jagah bhar deta hai

\vspace{1cm}  % Vertical: 1cm upar-neeche jagah

%--- LINE SPACING ---
% Preamble mein setspace package use karo:

Yeh normal spacing hai.

\bigskip   % Badi vertical jagah
\medskip   % Beech ki jagah
\smallskip % Chhoti jagah

\end{document}
📋 Spacing Quick Reference
CommandMatlabKitni jagah?
\,Thin space3/18 em
\quadEm space1 em (~font size)
\qquadDouble em2 em
\hspace{Xcm}Fixed horizontalTum batao
\vspace{Xcm}Fixed verticalTum batao
\hfillFill spaceBachi jagah bhar do
\smallskipChhoti jagah3pt
\medskipBeech ki6pt
\bigskipBadi jagah12pt
💻 Line Spacing Example
\documentclass{article}
\usepackage{setspace}  % Line spacing ke liye

\begin{document}

\singlespacing  % Normal (1x)
Yeh single spacing hai.

\onehalfspacing  % 1.5x spacing
Yeh derhaa spacing hai.

\doublespacing  % 2x spacing
Yeh double spacing hai.

\setstretch{1.8}  % Custom: 1.8x
Yeh custom 1.8x spacing hai.

\end{document}
⚠️ Common Mistake

\vspace{} paragraph ke beech kaam karta hai, paragraph start pe nahi. Agar koi effect nahi ho raha, toh \vspace*{} try karo (star wala force karta hai).

Line Breaking Line Todna / Naya Paragraph

📖 Kya Hai?

LaTeX mein line breaks aur paragraph breaks ka apna system hai. Simple Enter dene se line nahi todti — iske liye special commands hain.

📋 Line Break Methods
CommandMatlab
Empty line (double Enter)Naya paragraph shuru
\\Force line break (paragraph nahi)
\\[1cm]Line break + extra vertical space
\newline\\ ka alternative
\newpageNaya page force karo
\clearpageNaya page + sab figures flush karo
\noindentParagraph indentation hatao
\linebreakJustified line break
💻 Working Example
\documentclass{article}
\begin{document}

% Method 1: Naya paragraph (blank line)
Yeh pehla paragraph hai.

Yeh doosra paragraph hai. (Blank line se alag hua)

% Method 2: Force line break (same paragraph)
Pehli line hai. \\
Doosri line hai. \\[0.5cm]
Teesri line hai — upar 0.5cm gap ke saath.

% Method 3: Page break
Yeh page 1 pe hai.
\newpage
Yeh page 2 pe hai.

% Indentation control:
\noindent Yeh paragraph indent nahi hoga.

Normal paragraph indent hoga.

\end{document}
⚠️ Common Mistake

Beginners sochte hain ek Enter se line break hoga — nahi hoga! LaTeX ek Enter ko sirf space maanta hai. Do Enters (blank line) se naya paragraph, ya \\ se force line break.

💡 Tip

\\ sirf text environment mein use karo — math mode, headings, ya preamble mein nahi!

Columns Khaane / Stambh

📖 Kya Hai?

Document ki content ko 2 ya zyada columns (khaanon) mein baant sakte hain — jaise newspaper ya magazine mein hota hai!

💻 Working Example
\documentclass[twocolumn]{article}
% twocolumn option: poora document do columns mein

\begin{document}

\onecolumn  % Temporarily ek column karo
Yeh heading puri width mein hai.

\twocolumn  % Wapas do column

Lorem ipsum dolor sit amet, consectetur adipiscing elit.
Sed do eiusmod tempor incididunt ut labore et dolore magna
aliqua. Ut enim ad minim veniam, quis nostrud exercitation.

\end{document}
💡 Tip

Zyada control ke liye multicol package use karo (agla topic dekho). twocolumn page-level pe hota hai; multicol paragraph-level pe.

11

Multi-columns Kai Khaane Ek Saath

📖 Kya Hai?

multicol package se 2, 3, ya zyada columns bana sakte ho — sirf ek section ke liye bhi. Iska fayda yeh hai ki columns balanced (barabar bhari hui) hoti hain automatically.

💻 Working Example
\documentclass{article}
\usepackage{multicol}    % Package load karo
\usepackage{lipsum}     % Dummy text ke liye

\begin{document}

Yeh pehle single column mein hai — poori width.

\begin{multicols}{2}  % 2 columns shuru

\lipsum[1]  % Dummy text

\columnbreak  % Force karo doosra column start ho

\lipsum[2]

\end{multicols}  % 2 columns khatam

% 3 columns bhi ban sakte hain!
\begin{multicols}{3}
\lipsum[3]
\end{multicols}

% Column separator line ke saath:
\setlength{\columnsep}{20pt}   % Columns ke beech gap
\setlength{\columnseprule}{0.5pt} % Line ki thickness

\begin{multicols}{2}
Yeh column 1 hai. Beech mein ek line dikhe gi.

\columnbreak

Yeh column 2 hai.
\end{multicols}

\end{document}
📄 Output (2 column layout)
Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua...
Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat...
💡 Tips

• Headings normally single column mein rakhne ke liye: pehle heading likho, phir multicols shuru karo.
• Bahut thodi text ke liye multicols* use karo (balanced nahi hoga — last column shorter ho sakta hai).

Minipages Chhota Page — Page ke andar page!

📖 Kya Hai?

Minipage ek page ke andar chhota page hota hai! Iska use tab hota hai jab tum do cheezein side-by-side rakhna chahte ho — jaise ek image aur uski description ek saath, ya do code blocks alag-alag.

🔧 Syntax
\begin{minipage}[position]{width}
  Content yahan
\end{minipage}

% position: t (top), c (center), b (bottom)
% width: 0.4\textwidth ya koi bhi size
💻 Working Example
\documentclass{article}
\usepackage{xcolor}

\begin{document}

% Do minipages side by side
\begin{minipage}[t]{0.45\textwidth}
  \textbf{Left Box}
  
  Yeh left side ka content hai.
  Kuch bhi aa sakta hai yahan.
\end{minipage}
\hfill  % Do minipages ke beech jagah
\begin{minipage}[t]{0.45\textwidth}
  \textbf{Right Box}
  
  Yeh right side ka content hai.
  Lists bhi aa sakti hain:
  \begin{itemize}
    \item Pehli baat
    \item Doosri baat
  \end{itemize}
\end{minipage}

\vspace{1cm}

% Teen minipages!
\begin{minipage}{0.3\textwidth}
  \colorbox{red!20}{\parbox{\linewidth}{Box 1: Red}}
\end{minipage}
\hfill
\begin{minipage}{0.3\textwidth}
  \colorbox{green!20}{\parbox{\linewidth}{Box 2: Green}}
\end{minipage}
\hfill
\begin{minipage}{0.3\textwidth}
  \colorbox{blue!20}{\parbox{\linewidth}{Box 3: Blue}}
\end{minipage}

\end{document}
📄 Output
Left Box

Yeh left side ka content hai. Kuch bhi aa sakta hai yahan.
Right Box

Yeh right side ka content hai. Lists bhi aa sakti hain:
• Pehli baat
• Doosri baat
Box 1: Red
Box 2: Green
Box 3: Blue
⚠️ Common Mistake

Dono minipages ki combined width 1.0 se zyada nahi honi chahiye! Agar dono 0.5\textwidth hain, to beech mein \hfill ki jagah nahi bachegi. Use 0.48 ya 0.45 karo.

13

Page Numbering Page Ke Numbers

📖 Kya Hai?

LaTeX automatically page numbers deta hai — lekin tum inhe control kar sakte ho: kahan se shuru karein, kaunsi style mein (1,2,3 ya i,ii,iii ya A,B,C), ya bilkul hatana bhi.

💻 Working Example
\documentclass{article}
\begin{document}

% PAGE NUMBER STYLE:
\pagenumbering{arabic}    % 1, 2, 3 (default)
\pagenumbering{roman}     % i, ii, iii (lowercase)
\pagenumbering{Roman}     % I, II, III (uppercase)
\pagenumbering{alph}      % a, b, c
\pagenumbering{Alph}      % A, B, C

% Page number change karo:
\setcounter{page}{5}  % Ab yeh page 5 maana jayega

% Page number chhupao:
\thispagestyle{empty}  % Sirf is ek page ka number chhupao

% Poore document se numbers hatao:
\pagestyle{empty}

% Real Example: Thesis style
\pagenumbering{roman}    % TOC ke liye roman
\tableofcontents
\newpage
\pagenumbering{arabic}   % Main content ke liye arabic

Yeh page 1 hai.

\end{document}
💡 Tips

• Thesis mein common pattern: Cover page = no number, TOC = roman (i, ii, iii), Main content = arabic (1, 2, 3).
• \pagenumbering{} counter bhi reset karta hai — agar reset nahi chahiye toh sirf style change karo.

14

Footnotes Paad-tika / Tali-tippani

📖 Kya Hai?

Footnote matlab page ke neeche chhoti notes — books mein dekha hoga ¹ ya * se reference hota hai aur neeche explanation. LaTeX inhe automatically number karta hai aur neeche place karta hai!

🔧 Syntax
\footnote{Yahan apni note likho}
💻 Working Example
\documentclass{article}
\begin{document}

LaTeX\footnote{LaTeX ek document preparation system hai, 
Leslie Lamport ne banaya tha 1980s mein.} ek bahut powerful 
tool hai.

Einstein\footnote{Albert Einstein, 1879--1955, Nobel Prize winner.} 
ne kaha ki $E = mc^2$.

% Custom footnote symbol:
\footnote[*]{Star wali footnote!}

% Footnote manually set karo (table ke andar kaam aata hai):
Yahan ek note hai\footnotemark[3].

\footnotetext[3]{Yeh manually set ki gayi note #3 hai.}

\end{document}
📄 Output

LaTeX¹ ek bahut powerful tool hai.

Einstein² ne kaha ki E = mc².

¹ LaTeX ek document preparation system hai, Leslie Lamport ne banaya tha 1980s mein.

² Albert Einstein, 1879–1955, Nobel Prize winner.

⚠️ Common Mistake

\footnote{} table environment ke andar seedha kaam nahi karta! Wahan \footnotemark aur \footnotetext use karo.

Headers & Footers Sirlaikh aur Padlaikh

📖 Kya Hai?

Header = page ke upar text (jaise chapter name, document title).
Footer = page ke neeche text (jaise page number, date).

💻 Working Example
\documentclass{article}

% Basic style switch:
% \pagestyle{empty}   — koi header/footer nahi
% \pagestyle{plain}   — sirf page number (footer mein)
% \pagestyle{headings} — automatic chapter/section headings
% \pagestyle{myheadings} — tum control karo

\pagestyle{myheadings}
\markright{Mera Document --- 2025}

\begin{document}

Yeh text hai. Header mein "Mera Document --- 2025" aayega
aur footer mein page number.

% Sirf ek page ka style badlna:
\thispagestyle{empty}  % Is page pe koi header/footer nahi

\end{document}
💡 Tip

Asal mein powerful headers/footers ke liye fancyhdr package use karo — agla topic dekho!

💡 Tips

• [L] = Left, [C] = Center, [R] = Right.
• Double-sided documents mein [LE, RO] (Left Even, Right Odd) pages use karo.
• \thepage current page number deta hai, \today aaj ki date.

⚠️ Common Mistake

Hamesha \fancyhf{} pehle likho — warna purane default headers aur tumhare naye dono saath dikhenge!

Shortcuts & Definitions Apne Commands Banao!

📖 Kya Hai?

LaTeX mein tum apne khud ke commands bana sakte ho! Jaise agar baar baar \textcolor{red}{\textbf{Important}} likhna pad raha hai, toh ek shortcut bana lo: \important. Yahi hai custom commands ka jadoo!

🔧 Syntax
% Naya command define karo:
\newcommand{\commandname}[number_of_args]{definition}

% Purana command redefine karo:
\renewcommand{\commandname}{new_definition}
💻 Working Example
\documentclass{article}
\usepackage{xcolor}

%--- SIMPLE SHORTCUTS (no arguments) ---
\newcommand{\myname}{Amit Kumar Sharma}
\newcommand{\uni}{Indian Institute of Technology}
\newcommand{\R}{\mathbb{R}}  % Real numbers symbol

%--- WITH ARGUMENTS ---
\newcommand{\highlight}[1]{\textcolor{red}{\textbf{#1}}}
% [1] matlab 1 argument. #1 matlab woh argument yahan aayega.

\newcommand{\colortext}[2]{\textcolor{#1}{#2}}
% [2] matlab 2 arguments: #1 = colour, #2 = text

%--- WITH DEFAULT VALUE ---
\newcommand{\greet}[1][World]{Hello, #1!}
% [1][World] = 1 argument with default "World"

%--- RENEW: Existing command ko change karo ---
\renewcommand{\emph}[1]{\textcolor{blue}{\textit{#1}}}
% Ab \emph blue + italic ho jayega

\begin{document}

Mera naam hai: \myname

Main padhta hoon: \uni

Yeh \highlight{bahut zaroori} baat hai!

\colortext{violet}{Yeh violet text hai!}

\greet           % "Hello, World!" (default)
\greet[Rahul]    % "Hello, Rahul!"

Real numbers: $x \in \R$

\end{document}
📄 Output
Mera naam hai: Amit Kumar Sharma
Main padhta hoon: Indian Institute of Technology
Yeh bahut zaroori baat hai!
Yeh violet text hai!
Hello, World!
Hello, Rahul!
Real numbers: x ∈ ℝ
💡 Tips

• Command names mein sirf letters — koi numbers ya special characters nahi.
• \newcommand fail karega agar command pehle se exist karti ho — wahan \renewcommand use karo.
• Apne saare custom commands ek alag file mein rakho (jaise mymacros.tex) aur \input{mymacros} se include karo — professional approach yahi hai!
